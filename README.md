# 프롬프트 랩 (Prompt Lab)

프롬프트 엔지니어링을 **체계적으로 배우는** 학습 플랫폼입니다. 지엽적인 테크닉이
아니라 어떤 AI·어떤 주제에도 통하는 근본 원리를 순서대로 익히고, 엄선된 프롬프트
라이브러리에서 바로 꺼내 쓰며, 배운 것을 생성기에서 연습합니다.

## 세 가지 모드

- **📚 학습** — 프롬프트 엔지니어링 커리큘럼. 기초 → 역할/페르소나 → 맥락/제약 →
  예시 → 추론 유도 → 반복/개선 → 고급 패턴까지, 모듈·레슨 단위로 진도와 완료를
  추적합니다. 각 레슨은 개념 → 핵심 원칙 → 좋은 예/나쁜 예 → 체크리스트 → 연습으로
  구성됩니다.
- **🗂️ 라이브러리** — 카테고리별로 엄선한 수백 개의 재사용 가능한 프롬프트
  (바이브코딩, 소프트웨어 개발, 글쓰기, 학습, 리서치, 비즈니스, 이미지 생성 등).
  검색·카테고리·난이도·즐겨찾기로 필터링하고, 복사하거나 생성기로 보냅니다.
- **✨ 생성기** — 한국어 아이디어를 카테고리·스타일에 맞춰 최적화된 프롬프트로
  변환합니다. 배운 원리를 바로 적용하는 실습 공간입니다.

## 설치 및 실행

```bash
npm install       # 의존성 설치
npm run dev       # 개발 서버
npm run typecheck # 타입 체크
npm run lint      # 린트
npm run build     # 프로덕션 빌드 (tsc + vite)
npm run preview   # 빌드 미리보기
```

## 환경 변수

생성기의 백엔드 엔드포인트는 환경 변수로 설정할 수 있습니다(미설정 시 기본 프록시로
폴백). `.env.example` 참고.

```bash
VITE_API_ENDPOINT=https://your-backend.example.com/generate
```

## 기술 스택

- **React 18** · **TypeScript** · **Vite** · **Zustand** · **Tailwind CSS**

## 콘텐츠 구조

- `src/data/curriculum/*` — 학습 모듈과 레슨
- `src/data/library/*` — 카테고리별 프롬프트 라이브러리
- `src/data/types.ts` — 공용 데이터 모델
